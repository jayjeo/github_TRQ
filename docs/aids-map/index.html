40품목 대체·보완 지도

농산물 40개 품목의 수요를 AIDS(Almost Ideal Demand System)로 한 번에 추정해 얻은 교차가격탄력성입니다. 한 칸은 열 품목의 가격이 1% 오를 때 행 품목의 구매량이 몇 % 변하는가를 나타냅니다. 테두리를 두른 칸은 추정값을 보기 전에 상식적으로 대체재 또는 보완재로 기대한 품목 쌍입니다. 테두리 안의 색과 비교해 보십시오.

자료: 2022-04-07 ~ 2025-03-06, 주간 153점을 일별 1,065일로 보간 대칭성·동차성·합계 조건 부과, 모수 858개

→ 처치 품목별 통제군 제외 목록 격자 — 할당관세 처치 품목 11개의 가격(열)과 40개 품목의 구매량(행)만 모아, 논문의 민감도 분석에서 통제군에서 뺀 품목을 표시한 표입니다. 이 지도는 추정값만 보여 주며, 어떤 품목을 빼는지는 그 표에서 정합니다.

부호 읽는 법

Hicks 탄력성 > 0 → 대체재

가격이 오른 품목(열) 대신 행 품목을 더 삽니다. 예: 대파 값이 오르면 쪽파를 더 산다.

Hicks 탄력성 < 0 → 보완재

함께 쓰이는 품목이라, 한쪽 값이 오르면 다른 쪽도 덜 삽니다. 예: 배추 값이 오르면 김장 양념도 덜 산다.

대각선(자기가격)은 < 0이 정상

제 값이 오르면 덜 삽니다. 대체·보완 판정과는 상관없어 회색으로 칠했고, 칸을 누르면 값이 보입니다.

테두리: 상식적 기대

실선은 기대 대체재, 점선은 기대 보완재입니다. 실선 칸이 파랗고 점선 칸이 호박색이면 상식과 맞습니다.

행 i = 구매량이 반응하는 품목, 열 j = 가격이 바뀐 품목입니다. ● 표시는 할당관세가 적용된(처치) 품목입니다. Hicks(보상) 탄력성은 i↔j 부호가 늘 같고(대칭성 wieij = wjeji), 크기만 지출 비중의 비율만큼 다릅니다. Marshall(비보상) 탄력성은 여기에 소득효과(−wjηi)가 더해진 값입니다. 품목별 지출 비중이 작아 부호는 대개 같습니다. 대체·보완은 Hicks 기준(순대체·순보완)으로 판정합니다.

      기대쌍 대조표

      행을 누르면 히트맵에서 그 칸을 보여 줍니다. 「부호」는 추정된 Hicks 탄력성의 부호가 상식적 기대와 같은지(일치) 다른지(반대)만 나타냅니다. Hicks 탄력성은 A←B 와 B←A 의 부호가 같습니다.

      품목 쌍 (A – B)상식적 기대Hicks A←BB←Ase_adj (A←B)FGNLS 2회 A←B부호 (반복 수렴 · FGNLS 2회)근거

      읽을 때 주의할 점

      계산 방법. 탄력성은 복제 패키지의 Python 코드(AIDS_estimate.py, AIDS_elasticities.py)로 계산했습니다. 추정법은 Stata demandsys aids의 기본 옵션과 같습니다(NLS → FGNLS → 반복 FGNLS, 60회에 수렴). 「FGNLS 2회」는 같은 코드로 수렴 허용오차를 1e-3 으로 늦추고 FGNLS 를 2회에서 멈춘 값이며, 같은 옵션으로 돌린 Stata 결과와 계수 차이가 표준오차의 0.1% 이내입니다.

      상식적 기대쌍은 추정값을 보기 전에 정했다. 요리 용도(함께 쓰이는가, 같은 요리에서 서로 대신 쓰이는가)와 장보기(같은 용도로 바꿔 사는가)로 볼 때 대체 또는 보완으로 기대되는 30쌍(대체 16, 보완 14)에 테두리를 둘렀습니다. 기대가 덜 뚜렷한 8쌍은 표 끝에 참고로 넣었습니다.

      교차탄력성은 약하게 식별된다. 「FGNLS 2회」와 「반복 수렴」은 둘 다 일관된 추정량인데도, 처치→통제 칸에서 두 값의 차이가 중앙값 기준으로 보정 표준오차의 약 1.3배입니다. 지표를 바꿔 보면 색이 바뀌는 칸이 많습니다. 개별 칸의 값보다 전체적인 경향을 보십시오.

      보정 표준오차. se_adj = 표준오차 × √(1,065/153) ≈ 표준오차 × 2.64 입니다. 일별 보간 행이 서로 독립이 아니라는 점만 대략 보정한 값입니다. 이 지도는 추정값과 표준오차만 보여 주며 통계적 검정 결과는 싣지 않습니다. 처치 품목별로 통제군에서 뺄 품목의 판정 기준과 결과는 통제군 제외 목록 격자에 있습니다.

      자료와 처리. 40개 품목의 주간 가격·판매액을 품목별로 계절 조정한 뒤, 주간 값을 목요일에 두고 일별로 보간(PCHIP)했습니다. 가격은 명목가격입니다. 시금치 단위 변경(2023년 21주)을 kg 기준으로 맞췄고, 2025년 가격 기록은 판매 자료와 주 정의를 맞추려고 한 주 뒤로 옮겼습니다. 열무의 2025년 1~7주 판매액은 2024년 같은 주 값으로 채웠습니다. 자세한 내용은 논문과 복제 패키지를 보십시오.
